# Альфа-Бизнес: Умный кредитный кабинет предпринимателя (Frontend)

Фронтенд-приложение на **React + TypeScript + Vite + Tailwind CSS**, разработанное в рамках хакатона **Альфа-Будущее 2026** в строгом соответствии с архитектурными руководствами [`FRONTEND.md`](../FRONTEND.md) и [`BACKEND.md`](../BACKEND.md).

---

## 🚀 Быстрый старт

1. Установите зависимости (если еще не установлены):
   ```bash
   npm install
   ```

2. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```

3. Откройте в браузере: `http://localhost:3000`

---

## 🎯 Роли и ключевые возможности

Приложение реализует два полноценных интерфейса в фирменном дизайне Альфа-Банка:

### 1. Личный кабинет предпринимателя (`Client`)
* **Оформление заявки (T01–T03)**:
  * Пошаговый визард с автоподтягиванием карточки ИП по **ИНН из ЕГРИП**.
  * Выбор стадии бизнеса: `operating` (действующий) или `prelaunch` (новый).
  * Ввод финансовых потоков (выручка, расходы, чистый поток).
  * Drag-and-drop загрузка выписок и налоговых деклараций.
* **Трекинг жизненного цикла (State Machine Stepper)**:
  * Наглядное отображение прогресса по стадиям.
* **Сценарий 503 (`waiting_check`, T05)**:
  * Оповещение о временной недоступности ФНС/БКИ и кнопка ручного повтора проверки (`T06`).
* **Сценарий дозапроса сведений (`need_info`, T04/T11/T15)**:
  * Форма ответа клиентом на запросы банка с загрузкой дополнительных документов (`T10`).
* **Одобрение и оферта (`offer`, T08/T12)**:
  * Просмотр одобренной суммы, ставки и графика платежей.
  * **Умное встречное предложение (+6 месяцев)** с расчетом сниженного платежа.
  * Принятие оферты в один клик.
* **Отзыв заявки (`closed`, T17)**:
  * Возможность отозвать заявку по собственному желанию.
* **Прозрачный аудит**:
  * Полный модальный журнал всех переходов заявки (T01–T17) с фиксацией времени и инициатора (`client`, `system`, `analyst`).

---

### 2. Рабочее место аналитика банка (`BankEmployee`)
* **Очередь заявок на андеррайтинг**:
  * Мониторинг очереди (`review`), фильтры по статусам и уровню риска, поиск по ИНН/наименованию.
* **Досье заёмщика и экспертная оценка**:
  * Сверка заявленных финансовых данных с реестрами (ЕГРИП, БКИ, ФНС).
  * Детальный расчет коэффициента покрытия долга (**DSCR**) и скорингового балла (0–100).
  * Проверка стоп-факторов (просрочки БКИ, налоговые долги ФНС).
* **Панель принятия решений**:
  * `T12` — Одобрить оферту (настройка суммы, срока, ставки).
  * `T11` — Запросить сведения у заёмщика (`need_info`).
  * `T14` — Уточнены факты: направить на повторный скоринг (`checking`).
  * `T13` — Отказать с фиксацией кода причины и понятного комментария.
  * `T16` — Закрыть по некредитному препятствию (`closed`).

---

### 3. Быстрое переключение для жюри и демо
* В верхней навигационной панели доступен **тумблер моментального переключения роли**: `Клиент (ИП)` ⇄ `Аналитик банка`.
* **Переключатель тёмной темы**: поддержка светлого и тёмного режима с автосохранением в `localStorage` и адаптацией под системные настройки (`prefers-color-scheme`).
* Встроен автономный Mock-провайдер с персистентным хранением в `localStorage`: приложение полностью работает и интерактивно даже без запущенного бэкенда!

## 🏗 Структура проекта

```text
src/
├── api/             # HTTP клиенты (Axios, JWT Refresh, Mock Store)
├── context/         # AuthContext (управление сессией, токенами и ролями)
├── types/           # Доменные интерфейсы (Application, Scoring, State Machine T01–T17)
├── utils/           # Форматирование валюты (₽), дат, статус-маппинг
├── components/
│   ├── common/      # Кнопки, инпуты, карточки, модалки, алерты, загрузчик файлов
│   ├── layout/      # Navbar, поднавигация, AppLayout
│   ├── badges/      # Статусные бейджи State Machine и уровни риска
│   ├── application/ # Stepper, OfferCard, EgripCard, ScoringCard, NeedInfoModal
│   └── analyst/     # Панель решений андеррайтера (T11–T16)
└── pages/
    ├── auth/        # Вход и регистрация ИП
    ├── client/      # Дашборд, визард подачи заявки, детальный просмотр заявки
    ├── analyst/     # Очередь на андеррайтинг, досье проверки заявки
    └── dev/         # Визуализатор State Machine T01–T17
```

## 🔗 Интеграция с Backend (.NET 10)

* По умолчанию Vite проксирует запросы `/api/*` на `http://localhost:5000`.
* Поддерживается гибридный транспорт аутентификации:
  * Заголовок `Authorization: Bearer <JWT>`
  * HttpOnly Cookies (`withCredentials: true`)
  * Автоматический перехват 401 и ротация токенов через `/api/auth/refresh`.
